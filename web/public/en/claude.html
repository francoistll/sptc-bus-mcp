Utiliser les bus des Seychelles dans Claude

Le site est aussi un serveur MCP gratuit : une fois ajouté à Claude, vous pouvez lui demander « Quel est le prochain bus de Victoria à Beau Vallon ? » ou « Horaires de la ligne 20 le week-end » et Claude interroge directement la base d’horaires SPTC. Aucun compte ni clé API n’est nécessaire.

Adresse du serveur MCP
https://bus-seychelles.pages.dev/mcp

Outils : chercher_arret, prochains_passages, horaires_ligne (lecture seule).

Dans Claude (claude.ai, application bureau et mobile)

  1. Ouvrez Personnaliser → Connecteurs (Customize → Connectors).
  2. Cliquez sur Ajouter un connecteur personnalisé (Add custom connector).
  3. Nom : Bus Seychelles ; URL : l’adresse ci-dessus. Laissez vide l’authentification. Validez.
  4. Dans une conversation, activez le connecteur (menu « + » → Connecteurs) puis posez votre question.

Offre gratuite : un seul connecteur personnalisé possible. Offres Team/Enterprise : un propriétaire de l’organisation doit d’abord l’ajouter. Détails officiels : aide Claude.

Dans Claude Code (terminal)

claude mcp add --transport http bus-seychelles https://bus-seychelles.pages.dev/mcp

Autres clients MCP (Cursor, VS Code, etc.)

Ajoutez un serveur MCP distant de type « HTTP / Streamable HTTP » avec cette URL, sans en-tête d’authentification.

{ "mcpServers": { "bus-seychelles": { "url": "https://bus-seychelles.pages.dev/mcp" } } }

À savoir

  • Non officiel : horaires extraits des PDF publiés par la SPTC (sptc.sc/timetable), valables au 4 août 2026, théoriques, sans temps réel ni correspondances. Vérifiez aux arrêts en cas de doute.
  • Confidentialité : le serveur MCP est en lecture seule. Pour repérer les abus, il conserve 60 jours votre adresse IP et les paramètres de chaque appel (arrêts, ligne, heure).
  • Limite d’usage : 60 requêtes par minute et par adresse.
  • Code source et signalement d’erreurs : GitHub.

Use Seychelles buses in Claude

The site is also a free MCP server: once added to Claude, you can ask “What is the next bus from Victoria to Beau Vallon?” or “Route 20 timetable on weekends” and Claude queries the SPTC timetable database directly. No account or API key needed.

MCP server address
https://bus-seychelles.pages.dev/mcp

Tools: chercher_arret (find a stop), prochains_passages (next buses), horaires_ligne (route timetable), all read-only.

In Claude (claude.ai, desktop and mobile apps)

  1. Open Customize → Connectors.
  2. Click Add custom connector.
  3. Name: Bus Seychelles; URL: the address above. Leave authentication empty. Confirm.
  4. In a conversation, turn the connector on (“+” menu → Connectors), then ask your question.

Free plan: only one custom connector is allowed. Team/Enterprise plans: an organization owner must add it first. Official details: Claude help.

In Claude Code (terminal)

claude mcp add --transport http bus-seychelles https://bus-seychelles.pages.dev/mcp

Other MCP clients (Cursor, VS Code, etc.)

Add a remote MCP server of type “HTTP / Streamable HTTP” with this URL and no authentication header.

{ "mcpServers": { "bus-seychelles": { "url": "https://bus-seychelles.pages.dev/mcp" } } }

Good to know

  • Unofficial: timetables extracted from the PDFs published by SPTC (sptc.sc/timetable), valid as of 4 August 2026, scheduled times only, no real-time data and no transfers. Check at the stop if in doubt.
  • Privacy: the MCP server is read-only. To detect abuse, it keeps your IP address and each call's parameters (stops, line, time) for 60 days.
  • Usage limit: 60 requests per minute per address.
  • Source code and error reports: GitHub.
